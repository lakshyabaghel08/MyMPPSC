MyMPPSC · Phase 3 · artboards

The study desk

Four screens, one visual language: warm paper, a serif voice for what matters, hairlines instead of boxes, and a right margin that holds the facts that would otherwise become badges. Nothing on these boards is decorative — every rule separates two different jobs.

These are layout proposals for review, not the app. The current build is untouched.

0 · The kit

primitives · type · empty state

Three primitives, not cards

Content sits directly on the page and is separated by a hairline and rhythm. A bordered panel is reserved for things that interrupt the page — a dialog, an overlay, a scrollable table.

Sheet — the default

Paper, ink, a rule between sections.

Panel — interrupted

Dialog, overlay, scrolling data.

MarginMetadata, provenance and sample size.

Type does the hierarchy

Serif for the voice of the desk — the date, the next thing, a score, a question stem. Inter for everything operational. Small caps for section labels instead of headings inside boxes.
